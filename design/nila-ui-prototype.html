Design position

A home that appears only when needed.

NILA is a launcher first. The stable home preserves memory and calm; the temporary layer reshapes around one current intent.

Interaction grammar
01Rest on a quiet, familiar home.
02Form intent before showing choices.
03Prepare freely; commit visibly.
04Home always returns to home.
The mascot is a state cursor, not a destination. App icons remain available through the dock and drawer.
